# Curated SWORD modules

The layout follows Bible Resources conventions: `modules/<resource-id>/`. Keep verified source/edition metadata and review evidence next to each resource. A compiled SWORD package may be distributed as an independently pinned GitHub Release asset rather than duplicated as a large binary payload in Git.

## ISBE 1915

The corrected historical `BRISBE1915` dictionary **is compiled and publicly released** as [0.1.0](https://github.com/icfmp/Bible-Resources-ISBE/releases/tag/isbe-1915-v0.1.0). The release includes the validated SWORD ZIP/TAR, corrected source archive, and SHA-256 checksums; the native readback verified all **9,380 entries**.

[Module editorial record](isbe-1915/EDITORIAL.md) · [Source validation](isbe-1915/SOURCE_VALIDATION.json) · [Published evidence](../release/published/isbe-1915-v0.1.0/PUBLICATION_EVIDENCE.json)

There is deliberately **no** `modules/isbe-1915/payload/`: the release assets are the authoritative downloadable bytes. The original CrossWire binary has not been relabeled as the corrected edition. Known reader-specific navigation limitations and the incomplete 1915 print collation are documented in the release, not hidden.

Publication here does **not** imply integration into the separate Bible Resources central Pages catalogue.
