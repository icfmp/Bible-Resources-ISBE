# Curated SWORD modules

The layout follows Bible-Resources: `modules/<resource-id>/`. A real module requires a `payload/` with SWORD `mods.d/` and native binary files, independent full-corpus readback, reader tests and verified redistribution rights.

[ISBE 1915](isbe-1915/EDITORIAL.md) is **a prepared source-only module record**. A corrected compiled SWORD payload does not exist yet: it would be misleading to relabel CrossWire's unchanged original binary as our corrected edition. No empty or invented payload is committed.
