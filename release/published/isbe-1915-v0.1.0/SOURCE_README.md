# Bible Resources — ISBE 1915 corrected historical source, version 0.1.0

This source package contains the corrected English TEI P5 historical master,
the original CrossWire 2.2 acquisition/provenance manifests, the approved
cleanup manifest and a scope-limited editorial assessment.

- `ISBE.xml`: corrected historical master, SHA-256
  `5df8a6d1311e3f5a83a6d961c6e09c27e042b0c68b4a9da54cb98821cb878d2c`.
- `CLEANUP_MANIFEST.json`: reproducibility and approved alterations.
- `CROSSWIRE_PROVENANCE.json` and `ACQUISITION_MANIFEST.json`: original
  upstream digital source provenance, licensing and acquisition details.
- `EDITORIAL_ASSESSMENT.md`: automated corpus screening and carefully
  qualified visual/editorial observations.

The unchanged CrossWire original ZIP archive remains in the Git repository at
`sources/original/encyclopedias/en/isbe-crosswire-2.2/ISBE.zip`.
Its SHA-256 is
`4de747545d9c349ab724bc1708b01df5481e3b93e5e51077f859dd8a32023a32`.

The historical publication is dated 1915, and CrossWire's ISBE module declares
`Public Domain`, accepted by the project owner for distribution.
This is not an exhaustive five-volume printed collation and it does not claim
to reconstruct unrepresented printed script forms.

See https://github.com/icfmp/Bible-Resources-ISBE for full reproducible
source history, corrections and native SWORD module build tools.
