# Versioned print corrections to the separate 1915 ISBE edition

The preserved source witness, canonical cleaned/en/ISBE.xml, and the **31-entry repaired** TEI generated by scripts/finalize_1915_recovery.py are never edited in place.

The additional generic print-delta layer is a **third, separately generated editorial candidate**, not the canonical CrossWire edition. Its only approved v1 change corrects the printed cross-reference in AALAR: the 1915 volume-I folio 1 source says **See ALLAR**, while CrossWire says **See ALTAR**. The active target and visible label are updated to ALLAR. The old ref attribute n=ISBE:ALTAR stays intact to preserve the digital source's original navigation provenance.

## Evidence

- Original full-volume 1915 source image verified by SHA-256 and AI-assisted visual reading: [archival PDF, volume I, PDF page 25](https://github.com/icfmp/Bible-Resources-ISBE/actions/runs/45116299265).
- Source-locked comparison with exact stable source IDs: workspace/reviews/1915-nonempty-contrast-v1.json, merged in PR #45.
- Explicit editorial decision and reversal fields: workspace/reviews/1915-approved-print-deltas-v1.json.
- Generic, source-locked, id-stable implementation: scripts/apply_1915_print_deltas.py.

This is **not** a full historical-critical edition or independent human peer review. Neither the revised text nor the original has cleared downstream redistribution and translation rights (issue #1).

## Rebuild

Run scripts/finalize_1915_recovery.py first using the workflow parameters documented in docs/1915-recovered-entries.md. Then run:

~~~sh
python scripts/apply_1915_print_deltas.py \
  --source cleaned/en/ISBE.xml \
  --baseline workspace/tmp/ISBE-1915-approved-base.xml \
  --baseline-report workspace/tmp/ISBE-1915-approved-base-report.json \
  --baseline-manifest workspace/tmp/ISBE-1915-base-validator.json \
  --ledger workspace/reviews/1915-approved-print-deltas-v1.json \
  --output workspace/tmp/ISBE-1915-edited-nonpublishable.xml \
  --report workspace/tmp/ISBE-1915-print-deltas-report.json \
  --derived-manifest workspace/tmp/ISBE-1915-edited-validator.json \
  --fidelity workspace/tmp/ISBE-1915-edited-fidelity.json
~~~

The GitHub workflow validate-1915-print-deltas.yml reproduces the exact source-to-edition chain, independently checks the TEI P5 official schemas and generates a **nonpublishable** artifact. A changed original SHA, missing original target, absent printed destination, wrong unit ID, duplicated delta, altered unrelated article, lost XML ID or broken internal fragment must fail. Every changed text unit and navigation edge is recorded with before/after text SHA, reference SHA and stable IDs. Reversal consists of rebuilding from the preserved 31-entry baseline without applying this ledger.

Do not automatically promote any other suspected source-vs-print difference to a correction. In particular, AARON's Jehovah/Yahweh and run-in heading evidence need editorial scope decisions before modification.
