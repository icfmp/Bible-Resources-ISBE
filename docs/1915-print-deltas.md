# Versioned print corrections to the separate 1915 ISBE edition

The preserved source witness, canonical cleaned/en/ISBE.xml, and the **31-entry repaired** TEI generated by scripts/finalize_1915_recovery.py are never edited in place.

The additional generic print-delta layer is a **third, separately generated editorial candidate**, not the canonical CrossWire edition. Its first approved v1 change corrected the printed cross-reference in AALAR: the 1915 volume-I folio 1 source says **See ALLAR**, while CrossWire says **See ALTAR**. The active target and visible label are updated to ALLAR. The old ref attribute n=ISBE:ALTAR stays intact to preserve the digital source's original navigation provenance.

A second batch adds five source-backed operations from the original printed folios 1–3 of volume I; all six operations are applied sequentially to a *separate*, still nonpublishable TEI. Multiple changes to a single article are allowed only with separate exact source anchors, stable unit IDs and decisions.

Expected structural gates: 9,380 articles, five affected article subtrees and **9,375 unchanged**, all 185,659 original editorial-master IDs kept in original order, with **two** explicit new scripture-reference IDs. TEI P5 RELAX NG and Schematron must pass before adoption. The actual passing CI values, not these design expectations, determine approval.

**Deferred:** the original AARON article has printed bold run-in numbered headings while CrossWire uses separate underlined paragraphs. Reconstructing these as structural sections requires a dedicated document-wide model and print comparison, not a paragraph-specific workaround. Other apparent expansions of AV/RV/book abbreviations also remain individual review candidates, not automatic deletion or conversion rules.

## Rebuild

Run scripts/finalize_1915_recovery.py first using the workflow parameters documented in docs/1915-recovered-entries.md. Then run:

~~~sh
python scripts/apply_1915_print_deltas.py \
  --source cleaned/en/ISBE.xml \
  --baseline workspace/tmp/ISBE-1915-approved-base.xml \
  --baseline-report workspace/tmp/ISBE-1915-approved-base-report.json \
  --baseline-manifest workspace/tmp/ISBE-1915-base-validator.json \
  --ledger workspace/reviews/1915-approved-print-deltas-v1.json \
  --output workspace/tmp/ISBE-1915-edited-nonpublishable.xml \
  --report workspace/tmp/ISBE-1915-print-deltas-report.json \
  --derived-manifest workspace/tmp/ISBE-1915-edited-validator.json \
  --fidelity workspace/tmp/ISBE-1915-edited-fidelity.json
~~~

The GitHub workflow validate-1915-print-deltas.yml reproduces the exact source-to-edition chain, independently checks the TEI P5 official schemas and generates a **nonpublishable** artifact. A changed original SHA, missing original target, absent printed destination, wrong unit ID, duplicated delta, altered unrelated article, lost XML ID or broken internal fragment must fail. Every changed text unit and navigation edge is recorded with before/after text SHA, reference SHA where applicable, and stable IDs. For verified missing scripture references, the output ledger also records the original `cRef`, exact new `cRef` sequence and added identifiers. Reversal consists of rebuilding from the preserved 31-entry baseline without applying this ledger.

Do not automatically promote any other suspected source-vs-print difference to a correction. In particular, AARON's run-in heading structure and any unverified Yahweh/Jehovah substitutions outside the individually attested sentences remain deferred.
