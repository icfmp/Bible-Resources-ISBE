All full text sources live under **category / language / resource**, matching Bible-Resources.

- [Original CrossWire 2.2](original/encyclopedias/en/isbe-crosswire-2.2/) — exact upstream SWORD ZIP and immutable source/acquisition metadata. This is **not** the edited text.

There is no duplicate `sources/crosswire/` directory. Future **actual** modernized and translated editions get distinct real source folders inside `sources/cleaned/` when generated and reviewed. Source rights issue #1 remains open; local verification does not authorize release.
