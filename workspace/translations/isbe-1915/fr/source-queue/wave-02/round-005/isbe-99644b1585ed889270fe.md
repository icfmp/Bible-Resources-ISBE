# BUCKET
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
buk'-et (deli): The word is found only in ⟦ISBE:KEEP:3:Isa 40:15⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:Nu 24:7⟧, in the latter passage in a figurative use. The bucket was doubtless a waterskin with two cross-pieces at the top to fit it for use in drawing water, like those now in use in Palestine. The ordinary word for water-skin is a different one (no'dh).
