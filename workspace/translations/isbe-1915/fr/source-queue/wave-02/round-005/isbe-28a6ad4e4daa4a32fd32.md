# BETH-EZEL
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
beth-e'-zel (beth ha-'etsel; oikos echomenous autes; literally, "adjoining house"): A place named along with other cities in the Philistine plain (⟦ISBE:KEEP:3:Mic 1:11⟧). The site has not been identified. By some it is thought to be the same as Azel of ⟦ISBE:KEEP:4:Zec 14:5⟧; but see ⟦ISBE:OPEN:5⟧AZEL⟦ISBE:CLOSE:5⟧⟦ISBE:FIX:5:tail⟧
