# BLAINS
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
blanz (abha`bu`ah: only in ⟦ISBE:KEEP:3:Ex 9:9⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:10⟧): Pustules containing fluid around a boil or inflamed sore. It is an Old English word "bleyen," used sometimes as a synonym for boil. Wyclif (1382) uses the expression "stinkende bleyne" for Job's sores. The Hebrew word is from a root which means that which bubbles up.
