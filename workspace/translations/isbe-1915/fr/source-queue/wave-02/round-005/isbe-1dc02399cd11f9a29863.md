# BETH (1)
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
bath (b): The second letter of the Hebrew alphabet. With the daghesh it is transliterated in this dictionary as "b," and, without the daghesth, as "bh" ( = "v"). It came also to be used for the number two (2) and with the dieresis for 2,000.
