# BAALI
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ba'-a-li ba`ali, ("my master"): Baal, a common name for all heathen gods, had in common practice been used also of Yahweh. Hosea (⟦ISBE:KEEP:3:Ho 2:16⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:17⟧) demands that Yahweh be no longer called Ba`ali ("my Baal" = "my lord") but 'Ishi ("my husband"), and we find that later the Israelites abandoned the use of Ba`al for Yahweh.
