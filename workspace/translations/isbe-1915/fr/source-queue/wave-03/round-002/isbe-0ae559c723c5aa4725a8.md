# EBEZ
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
e'-bez ('ebhets, meaning unknown; Rhebes; the King James Version Abez):
<!-- ISBE-END:2 -->

<!-- ISBE-BLOCK:3 -->
One of the 16 cities in Issachar (⟦ISBE:KEEP:4:Jos 19:20⟧). The name seems to be cognate to that of the judge Ibzan (⟦ISBE:KEEP:5:Jud 12:8-10⟧). All else concerning it is conjecture.
