# DALETH
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
da'-leth (...): The 4th letter of the Hebrew alphabet, and as such used in ⟦ISBE:KEEP:3:Ps 119⟧ to designate the 4th section; transliterated in this Encyclopedia with the dagesh as d, and, without, as dh ( = th in "the"). It came also to be used for the number four (4), and with the dieresis for 4,000. With the apostrophe it is sometimes used as abbreviation for the tetragrammaton. For name, etc., see ⟦ISBE:OPEN:4⟧ALPHABET⟦ISBE:CLOSE:4⟧⟦ISBE:FIX:4:tail⟧
