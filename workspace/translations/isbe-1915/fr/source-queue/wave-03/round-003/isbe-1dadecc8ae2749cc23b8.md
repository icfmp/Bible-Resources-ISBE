# CONCISION
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
kon-sizh'-un (katatome, "mutilation," "cutting"): A term by which Paul contemptuously designates the merely fleshly circumcision upon which the Judaizers insisted as being necessary for Gentileconverts (⟦ISBE:KEEP:3:Php 3:2⟧), as distinguished from peritome, the true circumcision (⟦ISBE:KEEP:4:Php 3:3⟧). Compare ⟦ISBE:KEEP:5:Ga 5:12⟧ and ⟦ISBE:KEEP:6:De 23:1⟧, and see ⟦ISBE:OPEN:7⟧CIRCUMCISION⟦ISBE:CLOSE:7⟧⟦ISBE:FIX:7:tail⟧
