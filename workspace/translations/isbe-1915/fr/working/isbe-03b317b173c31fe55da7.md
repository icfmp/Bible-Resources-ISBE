# CONTENT ; CONTENTEMENT
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
kon-tent', kon-tent'-ment (ya`al ; arkeo) : Être exempt de souci parce que l'on est satisfait de ce que l'on possède déjà. L'hébreu signifie simplement « être satisfait ». Le grec fait ressortir toute la force du mot en ⟦ISBE:KEEP:3:1Ti 6:8⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:Heb 13:5⟧. Le contentement (⟦ISBE:KEEP:5:1Ti 6:6⟧) est plus intérieur que la satisfaction ; le premier est une disposition habituelle ou un état permanent de l'esprit, tandis que la seconde se rapporte à quelque événement ou objet particulier.
