# CHADIAS, HABITANTS DE ; CHADIASAI
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ka'-di-as, ka'-di-a-si (la Revised Version [britannique et américaine] : Codex Alexandrinus, Chadasai ; Codex Vaticanus, hoi Chadiasai) : Les habitants de la ville mentionnée ici revinrent avec Zorobabel, en même temps que les Ammidioi (1 Esdras 5.20). Le nom ne se trouve pas dans Esdras et Néhémie. On a considéré les Chadiasai comme les habitants de Kadès et les Ammidioi comme les habitants de Humta (⟦ISBE:KEEP:3:Jos 15:54⟧). Le lieu est peut-être identique au Kedesch de ⟦ISBE:KEEP:4:Jos 15:23⟧⟦ISBE:FIX:4:tail⟧
