# BANDER LES YEUX
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
blind'-fold (perikalupto) : Jeu courant chez les enfants de l'Antiquité : la personne aux yeux bandés recevait un coup sur la joue, puis devait deviner qui l'avait frappée ; on ne la relâchait pas avant qu'elle ait trouvé juste. Les persécuteurs du Christ lui infligèrent ce traitement (⟦ISBE:KEEP:3:Lu 22:64⟧⟦ISBE:FIX:3:tail⟧
