# CONFORMER ; CONFORME
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
kon-form', kon-form'-a-b'-l (summorphoo, « devenir ou être semblable », ou « de même forme ») : Indique un changement intérieur de nature qui se manifeste dans la vie extérieure (⟦ISBE:KEEP:3:Ro 8:29⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:Php 3:10⟧⟦ISBE:FIX:4:tail⟧⟦ISBE:KEEP:5:21⟧), tandis que suschematizo, « façonné selon » (⟦ISBE:KEEP:6:Ro 12:21⟧, Revised Version, britannique et américaine, King James Version « conformed »), se rapporte à ce qui est extérieur.
