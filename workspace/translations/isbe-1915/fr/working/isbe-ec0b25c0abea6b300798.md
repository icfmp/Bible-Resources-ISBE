# DIMNA
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
dim'-na (dimnah, « fumier » ; Damna) : Ville des Lévites merarites sur le territoire de Zabulon (⟦ISBE:KEEP:3:Jos 21:35⟧). Le nom résulte probablement d'une erreur de copiste pour Rimmon.
