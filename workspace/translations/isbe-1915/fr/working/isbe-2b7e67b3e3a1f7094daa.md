# BERIA ; BERIITES
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
be-ri'-a, be-ri'-its (beri`ah, « dans les cris », probablement dérivé d'une racine hébraïque signifiant « faire du bruit », ou « dans le malheur », d'une autre racine hébraïque) :

<!-- ISBE-END:8 -->
