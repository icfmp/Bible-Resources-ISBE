# TORRENT DE BESOR
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
be'-sor (nachal besor ; Codex Alexandrinus : Bechor ; Codex Vaticanus : Beana ; ⟦ISBE:KEEP:3:1Sa 30:9⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:20⟧⟦ISBE:FIX:4:tail⟧⟦ISBE:KEEP:5:21⟧ ; Josèphe, Antiquités, VI, xiv, 6) : Lit de torrent (nachal) mentionné dans le récit de la poursuite des Amalécites par David.
