# BAALI
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ba'-a-li, ba`ali (« mon maître ») : Baal, nom courant désignant toutes les divinités païennes, avait aussi été utilisé dans l'usage courant pour désigner Yahvé. Osée (⟦ISBE:KEEP:3:Ho 2:16⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:17⟧) demande que Yahvé ne soit plus appelé Ba`ali (« mon Baal », c'est-à-dire « mon seigneur »), mais 'Ishi (« mon mari ») ; nous constatons qu'ultérieurement les Israélites abandonnèrent l'emploi de Ba`al pour Yahvé.
