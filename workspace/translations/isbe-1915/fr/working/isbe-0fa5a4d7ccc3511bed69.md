# PRODUIRE ; SE REPRODUIRE (BREED)
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
bred : Se trouve au passé en ⟦ISBE:KEEP:3:Ex 16:20⟧ comme traduction de rum = « faire monter », « s'élever ». Dans ce verset, il est dit que la manne s'est soulevée, c'est-à-dire qu'elle est « devenue vivante » (de vers), pour indiquer que les dons de Dieu sont gâtés par une accumulation égoïste et avare. Le présent actif se rencontre en ⟦ISBE:KEEP:4:Ge 8:17⟧ pour sharats = « se tortiller », « grouiller », « abonder », d'où « se multiplier abondamment » ; et en ⟦ISBE:KEEP:5:De 32:14⟧ pour ben = « fils », « descendant », « enfant », « poulain », « veau », « race ». Le participe présent se trouve en Ze 2.9 dans la King James Version pour mimshaq, dérivé de mesheq = « possession », « territoire », « champ ». Le passage en question devrait donc être traduit « champ d'orties » (la Revised Version [britannique et américaine] donne « possession d'orties »).
