# DÉBAUCHE SEXUELLE (CHAMBERING)
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
cham'-ber-ing : Relations sexuelles illicites ; traduction, dans les versions anglaises de la Bible depuis Tyndale, de koitias (littéralement « lits », ⟦ISBE:KEEP:3:Ro 13:13⟧). L'usage grec a des parallèles chez les auteurs classiques et dans la Septante ; comme le participe anglais, il désigne des actes répétés ou habituels. Le mot n'est pas attesté ailleurs dans la littérature anglaise comme verbe ou participe en ce sens ; dans Othello, iii, 3, un chamberer est un intrigant, un homme débauché ; dans Werner de Byron, IV, 1, 404, un galant ou chevalier de salon ; et dans Clerk's Tale de Chaucer, 766, une concubine.
