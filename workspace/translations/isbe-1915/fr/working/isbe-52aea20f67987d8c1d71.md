# GÉNÉROSITÉ ; LIBÉRALITÉ (BOUNTIFULNESS; BOUNTY)
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
boun'-ti-fool-nes, boun'-ti (haplotes, « simplicité », « bienveillance », ⟦ISBE:KEEP:3:2Co 9:11⟧ King James Version ; Tobh, « être bon » (⟦ISBE:KEEP:4:Pr 22:9⟧) ; eulogia, « bonne parole », « bénédiction » (⟦ISBE:KEEP:5:2Co 9:6⟧) ; gamal, « bien traiter » (⟦ISBE:KEEP:6:Ps 119:17⟧) ; shoa`, « être généreux » (⟦ISBE:KEEP:7:Isa 32:5⟧) ; yadh, « main », « puissance ») : Paul parle de l'Église de Corinthe « enrichie en toutes choses pour toute libéralité » (King James Version : « bountifulness », générosité, ⟦ISBE:KEEP:8:2Co 9:11⟧). L'offrande de l'Église de Corinthe pour les chrétiens de Judée est appelée une « bounty », une bénédiction donnée généreusement : « et non par extorsion » (King James Version : « of covetousness », par cupidité, ⟦ISBE:KEEP:9:2Co 9:5⟧⟦ISBE:FIX:9:tail⟧⟦ISBE:KEEP:10:6⟧). Le mot apparaît aussi en ⟦ISBE:KEEP:11:1Ki 10:13⟧: « Outre ce que Salomon lui donna de sa libéralité royale », littéralement « selon la main du roi Salomon ».
