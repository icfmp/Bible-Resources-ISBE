# CHAVAH
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ka'-va (Septante : Zoe) : Transcription de l'hébreu chawwah ou chavvah, qui signifie « celle qui donne la vie », « vivante », et apparaît dans nos versions anglaises sous le nom d'Ève (⟦ISBE:KEEP:3:Ge 3:20⟧ ; voir la note marginale de la King James Version).
