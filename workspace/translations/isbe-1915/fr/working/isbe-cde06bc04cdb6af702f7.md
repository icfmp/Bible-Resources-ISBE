# CAUSE
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
kos : Dans la King James Version comme dans la Revised Version (britannique et américaine), « for this cause » (King James Version : « cause ») apparaît en ⟦ISBE:KEEP:3:Ex 9:16⟧ comme traduction de ba`abhur zo'th = « afin que », « dans le but que » ; de même en ⟦ISBE:KEEP:4:Da 2:12⟧ pour kol-qebhel denah, et en ⟦ISBE:KEEP:5:2Ch 32:20⟧ King James Version pour `al-zo'th, où les Revised Versions lisent « because of » (à cause de). Dans le Nouveau Testament, le mot est employé adverbialement dans la traduction de plusieurs expressions grecques : heneka toutou (⟦ISBE:KEEP:6:Mt 19:5⟧⟦ISBE:FIX:6:tail⟧⟦ISBE:KEEP:7:Mr 10:7⟧) ; dia touto, ⟦ISBE:KEEP:8:Joh 12:27⟧⟦ISBE:FIX:8:tail⟧⟦ISBE:KEEP:9:Ro 1:26⟧⟦ISBE:FIX:9:tail⟧⟦ISBE:KEEP:10:13:6⟧⟦ISBE:FIX:10:tail⟧⟦ISBE:KEEP:11:15:9⟧ (Revised Version [britannique et américaine] : « therefore », c'est pourquoi) ; ⟦ISBE:KEEP:12:1Co 11:30⟧⟦ISBE:FIX:12:tail⟧⟦ISBE:KEEP:13:1Th 2:13⟧⟦ISBE:FIX:13:tail⟧⟦ISBE:KEEP:14:2Th 2:11⟧⟦ISBE:FIX:14:tail⟧⟦ISBE:KEEP:15:1Ti 1:16⟧⟦ISBE:FIX:15:tail⟧⟦ISBE:KEEP:16:Hebrews 9:15⟧ ; eis touto, ⟦ISBE:KEEP:17:Joh 18:37⟧ (où la King James Version, variant l'expression, lit « to this end », « for this cause ») ; ⟦ISBE:KEEP:18:1Pe 4:6⟧ King James Version ; toutou charin, ⟦ISBE:KEEP:19:Eph 3:14⟧. On trouve des traductions inhabituelles, comme « for his cause » (= « à cause de »), ⟦ISBE:KEEP:20:2Co 7:12⟧ ; au sens d'« affaire », « chose », désuet dans la King James Version, ⟦ISBE:KEEP:21:1Ki 12:15⟧⟦ISBE:FIX:21:tail⟧⟦ISBE:KEEP:22:2Ch 10:15⟧, où le mot apparaît comme paraphrase de necibbah (= « tournure des événements »). En ⟦ISBE:KEEP:23:1Sa 25:31⟧ (King James Version, Revised Version [britannique et américaine]), « causeless » (= « sans cause », American Standard Revised Version) apparaît arbitrairement au sens adverbial.
