# ENSEVELISSEUR
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ber'-i-er (kabhar) : « On posera un signe près de lui, jusqu'à ce que les ensevelisseurs l'aient enterré » (⟦ISBE:KEEP:3:Eze 39:15⟧). « Lorsque ceux qui parcouraient le pays pour l'examiner trouvaient des restes humains, ils devaient dresser un signe afin d'attirer l'attention des ensevelisseurs qui les suivaient » (Commentary de Dummelow, sur ce passage).
