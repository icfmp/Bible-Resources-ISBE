# BANNAS
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ban'-as (Bannos ; King James Version : Banuas) : Nom figurant dans la liste des personnes revenues de captivité avec Zorobabel (1 Esdras 5.26). Bannas et Sudias correspondent à Hoodaviah dans les listes d'Esdras et de Néhémie.
