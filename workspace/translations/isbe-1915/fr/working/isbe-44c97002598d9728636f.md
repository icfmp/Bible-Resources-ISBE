# CONTRADICTION
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
kon-tra-dik'-shun : King James Version pour antilogia (⟦ISBE:KEEP:3:Heb 7:7⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:12:3⟧). Dans le premier passage, la Revised Version (britannique et américaine) porte « without any dispute » (sans aucune contestation), c'est-à-dire que ce qui a été dit ne demande aucune argumentation ; dans le second, « gainsaying » (opposition verbale), ce qui n'est guère une amélioration, puisqu'il s'agit des attaques verbales contre les paroles et le caractère de Jésus.
