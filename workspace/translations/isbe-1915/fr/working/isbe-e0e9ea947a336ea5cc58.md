# FOSSÉ
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
dich : Le mot est employé sans distinction dans la King James Version pour représenter au moins trois idées différentes : une conduite ou un fossé (⟦ISBE:KEEP:3:2Ki 3:16⟧) ; un réservoir ou une citerne ; ou simplement une fosse ou un trou dans le sol. Dans la Revised Version (britannique et américaine), cette distinction est observée plus soigneusement. Comparer ⟦ISBE:KEEP:4:Job 9:31⟧⟦ISBE:FIX:4:tail⟧⟦ISBE:KEEP:5:Ps 7:15⟧ (« pit », fosse) et ⟦ISBE:KEEP:6:Isa 22:11⟧ (« reservoir », réservoir), le premier désignant une fosse ou quelque lieu semblable de destruction ou de corruption ; le second, un réservoir ou une citerne d'eau. L'usage du Nouveau Testament (⟦ISBE:KEEP:7:Mt 15:14⟧ King James Version) correspond quelque peu au premier. Voir aussi ⟦ISBE:KEEP:8:2Ki 3:16⟧ (« trenches », tranchées).
