# BEÉROTH-BENÉ-JAAKAN
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ben'-e-ja'-a-kan (be'eroth bene ya`aqan ; note marginale de la Revised Version : « les puits des fils de Jaakan ») : Campement des Israélites dans le désert, mentionné avant Moséra (⟦ISBE:KEEP:3:De 10:6⟧). En ⟦ISBE:KEEP:4:Nu 33:31⟧⟦ISBE:FIX:4:tail⟧⟦ISBE:KEEP:5:32⟧, le lieu est appelé simplement « Bené-Jaakan » et se trouve placé après Moséroth.
