# BARACHIE
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
bar-a-ki'-a (Barachias ; Barachias dans la King James Version ; ⟦ISBE:KEEP:3:Mt 23:35⟧) : Père de Zacharie, assassiné entre le sanctuaire et l'autel. Il est possible qu'il s'agisse de Zacharie, fils de Jehojada (⟦ISBE:KEEP:4:2Ch 24:20⟧ et suivants), que Matthieu appelle par erreur « Z., fils de Barachie ». ⟦ISBE:KEEP:5:Lu 11:51⟧ omet le nom du père de Z. (comparer le Kommentar de Zahn, p. 649, note).
