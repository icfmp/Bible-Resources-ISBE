# DRACHME ; DRAM
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
drak'-ma, (drachme) : Le mot est employé dans la Septante pour rendre beqa`, « demi-sicle », qui doit désigner l'étalon léger du sicle, car son poids était d'environ 62 grains. Dans le Nouveau Testament, le mot ne figure qu'en ⟦ISBE:KEEP:3:Lu 15:8⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:9⟧, où il est rendu par « une pièce d'argent » (en marge « drachme »). On la tenait communément pour équivalente au denier romain, bien qu'elle ne le fût pas exactement.
