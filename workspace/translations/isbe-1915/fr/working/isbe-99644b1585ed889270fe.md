# SEAU
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
buk'-et (deli) : Le mot se rencontre seulement en ⟦ISBE:KEEP:3:Isa 40:15⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:Nu 24:7⟧, avec un emploi figuré dans le second passage. Ce seau était sans doute une outre munie de deux traverses à son sommet pour permettre de puiser de l'eau, semblable à celles utilisées aujourd'hui en Palestine. Le mot ordinaire pour désigner une outre est différent (no'dh).
