# TRAÎTRES
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
be-tra'-ers (prodotai, « ceux qui trahissent », « traîtres ») : Étienne reprocha aux Juifs d'avoir trahi le Juste (⟦ISBE:KEEP:3:Ac 7:52⟧), c'est-à-dire de s'être associés à l'acte de Judas ; comparer ⟦ISBE:KEEP:4:Lu 6:16⟧ : « Judas Iscariot, qui devint traître » ; ⟦ISBE:KEEP:5:2Ti 3:4⟧ : « traîtres ».
