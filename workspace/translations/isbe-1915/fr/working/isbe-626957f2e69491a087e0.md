# DORYMÈNE
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
do-rim'-e-nez (Dorumenes) : Père de Ptolémée Macron (1 Macc 3:38 ; 2 Macc 4:45) ; probablement le même homme que celui qui combattit Antiochos le Grand (Polyb. v.61).
