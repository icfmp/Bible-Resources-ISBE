# BITHRON
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
bith'-ron (ha-bithron ; holen ten parateinousan, littéralement « tout le [territoire] qui s'étend » ; ⟦ISBE:KEEP:3:2Sa 2:29⟧, « le Bithron », c'est-à-dire la gorge ou le ravin) : Il ne semble pas s'agir d'un nom propre ; il désigne plutôt la gorge par laquelle Abner s'approcha de Mahanaïm. Buhl (GAP, 121) préfère l'identification avec le Wady `Ajlun, le long duquel, à une époque ultérieure, une route « Ro » reliait `Ajlun et Mahanaïm. D'autres (Guthe, Kurz. bib. Worterbuch, à ce mot) penchent pour le Wady esh Sha`ib.
