# SERVANTE ESCLAVE (BONDMAID)
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
bond'-mad : N'apparaît que trois fois dans la King James Version (⟦ISBE:KEEP:3:Le 19:20⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:25:44⟧⟦ISBE:FIX:4:tail⟧⟦ISBE:KEEP:5:Ga 4:22⟧ [la Revised Version (britannique et américaine) donne « handmaid »]). Le premier cas est celui d'une jeune fille hébraïque qui, par naissance, achat ou autrement, est entrée dans un esclavage temporaire. Le mot est ici shiphchah. Il apparaît souvent dans l'Ancien Testament, mais est traduit ailleurs par « maid », « handmaid », « woman servant », « maidservant » (servante), etc. L'autre cas (⟦ISBE:KEEP:6:Le 25:44⟧) concerne des jeunes filles esclaves étrangères et emploie un mot différent, 'amah, qui apparaît également à plusieurs reprises, mais est traduit ailleurs par « handmaid », etc. Le cas du Nouveau Testament (⟦ISBE:KEEP:7:Ga 4:22⟧) se rapporte à Agar, l'esclave égyptienne d'Abraham. Le mot original, paidiske, apparaît plusieurs autres fois, mais dans la King James Version est traduit ailleurs par « maid », « damsel » (jeune fille), etc. Il signifie une jeune fille esclave.
