# KERAN
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ke'-ran (keran) : Nom d'un clan horien qui figure dans la généalogie de Séir, le Horien (⟦ISBE:KEEP:3:Ge 36:26⟧), et dans la liste parallèle en ⟦ISBE:KEEP:4:1Ch 1:41⟧. Dillmann le fait dériver de kar, « un agneau ».
