# LIEU DE REPOS
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
kouch'-ing-plas (marbets ; une fois dans les versions anglaises de la Bible, ⟦ISBE:KEEP:3:Eze 25:5⟧) : Le même mot hébreu, cependant, qui signifie simplement « lieu où se coucher » pour les animaux au repos, est également employé en Soph 2:15, où la traduction est « un lieu ... pour s'y coucher ». Cette image, courante dans l'Écriture (voir aussi ⟦ISBE:KEEP:4:Isa 17:2⟧⟦ISBE:FIX:4:tail⟧⟦ISBE:KEEP:5:27:10⟧), suggère la désolation.
