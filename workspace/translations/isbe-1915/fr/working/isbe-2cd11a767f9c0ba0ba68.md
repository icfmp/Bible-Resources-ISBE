# BETH-LEAPHRA
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
beth-le-af'-ra (beth le`aphrah ; Septante ex oikou kata gelota, « maison de poussière ») : Nom d'un lieu qui ne se trouve qu'en ⟦ISBE:KEEP:3:Mic 1:10⟧. D'après le contexte dans lequel il est employé, ce lieu se situait probablement dans la plaine philistine. Il semble y avoir un jeu de mots sur le nom dans la phrase « à Beth le-`apharah je me suis roulé dans la poussière », `aphrah signifiant « poussière », et peut-être un autre jeu de mots sur « Philistin » dans le verbe « se rouler », hith-palldshithi (voir G. A. Smith, The Book of the Twelve Prophets, called Minor, au passage cité).
