# TISON
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
Le mot possède deux sens : un objet enflammé et des objets servant à alimenter un feu. Le premier est exprimé par 'udh, « bâton recourbé » servant à remuer le feu (⟦ISBE:KEEP:3:Am 4:11⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:Zec 3:2⟧ ; comparer ⟦ISBE:KEEP:5:Isa 7:4⟧) ; le deuxième par lappidh, en ⟦ISBE:KEEP:6:Jud 15:4⟧⟦ISBE:FIX:6:tail⟧⟦ISBE:KEEP:7:5⟧. Un troisième sens se trouve dans ziqah, désignant le tison comme moyen de propager le feu (⟦ISBE:KEEP:8:Pr 26:18⟧⟦ISBE:FIX:8:tail⟧
