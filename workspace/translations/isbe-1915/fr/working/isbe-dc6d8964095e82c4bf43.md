# INCLINÉ
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
bou'-ing (naTah, « incliner », « bomber ») : Les assaillants du psalmiste s'attendaient à le voir devenir « comme une muraille inclinée » (King James Version : « courbée ») (⟦ISBE:KEEP:3:Ps 62:3⟧) sous leur attaque commune, comme lorsqu'un mur mal construit, bombé, cède sous une pluie soudaine et violente (comparer ⟦ISBE:KEEP:4:Eze 13:11⟧⟦ISBE:FIX:4:tail⟧⟦ISBE:KEEP:5:38:22⟧⟦ISBE:FIX:5:tail⟧
