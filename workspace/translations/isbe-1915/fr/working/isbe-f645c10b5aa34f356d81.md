# DEHAÏTES
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
de-ha'-tez (dehawe' ; King James Version Dehavites) : Peuple énuméré en ⟦ISBE:KEEP:3:Ezr 4:9⟧ avec les Élamites, ere, parmi ceux que le roi assyrien Osnappar (Assurbanipal) établit en Samarie. L'identification est incertaine.
