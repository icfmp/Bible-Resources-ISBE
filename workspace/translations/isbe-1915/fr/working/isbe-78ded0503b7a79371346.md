# CUSCHAN
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
kushan : Dans le psaume d'Habakuk (⟦ISBE:KEEP:3:Hab 3:7⟧), « les tentes de Cuschan » sont mentionnées dans une description individualisée des effets d'une théophanie. L'expression parallèle est « les tentures du pays de Madian ». La Septante traduit Cuschan, kushan, par Aithiopon, lisant peut-être kushim ou kushin (kushin). Le contexte indique que le même pays ou peuple est visé que celui que l'Ancien Testament appelle ailleurs Cusch, mais de façon vague et non dans un sens géographique strict qui le limiterait à l'Afrique.
