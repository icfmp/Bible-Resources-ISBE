# CHASEBA
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
kas'-e-ba (Chaseba) : Nom d'une famille de serviteurs du Temple dans la liste de ceux qui revinrent de Babylone (1 Esdras 5.31). Ce nom ne figure pas dans les passages parallèles d'Esdras et de Néhémie.
