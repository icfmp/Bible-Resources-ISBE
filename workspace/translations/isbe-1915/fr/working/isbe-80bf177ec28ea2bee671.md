# DÉNONCER (DENOUNCE)
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
de-nouns' : Se trouve en ⟦ISBE:KEEP:3:De 30:18⟧ : « Je vous déclare aujourd'hui que vous périrez certainement. » Le mot est ici employé au sens désuet de « déclarer », faire connaître solennellement. Il ne se trouve pas dans la Bible avec le sens ordinaire de « censurer », « mettre en accusation », etc.
