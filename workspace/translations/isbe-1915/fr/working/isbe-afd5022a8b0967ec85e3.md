# KIDON, AIRE DE
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
ki'-don, (goren kidhon ; Septante B, omission ; A porte Cheilo) : Lieu où Uzza périt pour avoir touché l'arche (⟦ISBE:KEEP:3:1Ch 13:9⟧). En ⟦ISBE:KEEP:4:2Sa 6:6⟧ elle est appelée aire de Nacon. Aucun nom ressemblant à l'un ou l'autre n'a été découvert.
