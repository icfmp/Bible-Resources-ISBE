# BETH-HAGGAN
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
beth-hag'-an (beth-ha-gan, « maison du jardin ») : Lieu où Achazia fut tué par Jéhu (⟦ISBE:KEEP:3:2Ki 9:27⟧). Les versions anglaises de la Bible rendent ces mots par « la maison du jardin », mais certains les considèrent comme un nom propre. L'emplacement est incertain.
