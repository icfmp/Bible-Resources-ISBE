# BÉRITES
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
be'-rits (berim ; selon Klostermann et d'autres, bikhrim) : Le mot ne se rencontre qu'une fois dans l'Ancien Testament (⟦ISBE:KEEP:3:2Sa 20:14⟧). Le passage semble douteux. La proposition de Klostermann n'améliore en rien les choses ; il faut préférer l'autre lecture proposée, bachrim (Vulgate : viri electi), « jeunes hommes choisis ».
