# BETH-CAR
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
beth'-kar (beth-kar ; Baithchor, Belchor) : « Les hommes d'Israël sortirent de Mitspa, poursuivirent les Philistins et les frappèrent jusqu'à ce qu'ils arrivent au-dessous de Beth-Car » (⟦ISBE:KEEP:3:1Sa 7:11⟧). `Ain Karem a été proposé ; si Mitspa est nebi Samwil, cette identification est probable, car la poursuite aurait suivi le profond Wady beit Hannineh, voie naturelle de retraite pour les Philistins.
