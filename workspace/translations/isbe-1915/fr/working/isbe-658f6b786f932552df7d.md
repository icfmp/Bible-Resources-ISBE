# IL FAUT
<!-- ISBE-END:1 -->

<!-- ISBE-BLOCK:2 -->
be-hoov' : Dans le Nouveau Testament, ce terme traduit deux mots grecs, dei (⟦ISBE:KEEP:3:Lu 24:26⟧⟦ISBE:FIX:3:tail⟧⟦ISBE:KEEP:4:Ac 17:3⟧) et opheilo (⟦ISBE:KEEP:5:Heb 2:17⟧) : le premier exprime une nécessité physique, le second une nécessité morale (Bengelon, ⟦ISBE:KEEP:6:1Co 11:10⟧). Le premier signifie « il faut », c'est-à-dire que cela est exigé par l'ordre établi par Dieu ; le second « on doit », c'est-à-dire que cela est dû comme une dette.
